# 可执行手册

按工作场景组织，每篇给出适用条件、编号步骤、判断标准和常见坑。由 ai-work-radar 把“建议采用 / 值得一试”的调研自动合并进来并持续修订，**均未经实测**；人工验证过的做法在 [experiences/](../experiences/)。
