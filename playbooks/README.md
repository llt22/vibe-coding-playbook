# 可执行手册

按工作场景组织，每篇给出适用条件、编号步骤、判断标准和常见坑。由 ai-work-radar 把“建议采用 / 值得一试”的调研自动合并进来并持续修订，**均未经实测**；人工验证过的做法在 [experiences/](../experiences/)。

| 手册 | 解决的问题 | 先试这一步 | 最近修订 |

| [把“是否通过/属于哪类/打几分”的判断从通用大模型里拆出来做小范围对照实验](route-judgments-to-small-models.md) | 当你想把分类、门禁、排序这类判断从通用大模型里拆出来，用更便宜的决策模型降本提速时，如何做一次可对照、可回退的小范围实验。 | 挑一个你已经在用通用 LLM 做的、能表达成是/否或分类的门禁任务（例如“这条消息是否明确要求退款”），取 100–200 条有正确标签的历史样本，按字符串/字符串数组/键值对构造 state，跑一次与现有方案的对照。 | 2026-10-02 |
