## 是什么

`petekp/inbox` 是一个 Claude Code 插件（mod），把会话中散落的问题、任务、议题和机会收集到一个面板里，与你的会话并排显示。入口是 `/inbox` 命令。面板分三个标签页：

- **Needs you**：Claude 问你的问题、只有你能做的任务、失败的测试或构建。
- **Findings**：Claude 在任务之外注意到的 bug、风险和想法。
- **PRs**：来自本会话和当前分支的 pull request、各自的阻塞项、等你处理的 review 评论。

每条都标出可执行的动作：按答案旁的字母就把答案作为消息发给 Claude；也可以让 Claude 修一个 finding、把任务标完成、或忽略不需要的项。

它还会核对测试/构建状态：Claude 把每个测试或构建作为独立命令运行，插件据此知道结果；如果 Claude 说某件事通过了，但上次运行失败、或改动后没再跑过，插件会要求 Claude 重跑，或声明该改动未经测试。

## 具体做法（编号步骤；可直接复制的命令、配置、提示词原样放进代码块；写清每步的前提）

1. 前提：已安装并运行 Claude Code（作者在 2.1.292 上构建和测试）。在 Claude Code 会话内输入：

```
/plugin install inbox --marketplace petekp/inbox
```

   出现提示时回答 `y` 添加 marketplace，然后选择一个 scope。安装后在该会话即开始工作。

2. 前提：想用 PRs 标签页时，需要安装并登录 GitHub CLI `gh`。

3. 使用：直接输入 `/inbox` 打开面板。面板内快捷键：

```
1 / 2 / 3   切换标签页
j / k       上下移动
动作字母     执行该动作
ctrl+x      在面板与会话之间切换
```

   也可以鼠标点击。要回答某个问题，按答案旁的字母，答案会作为你的消息发给 Claude。当前标签页为空、而别处有新项到达时，面板会自动切过去。

4. 前提：会话空闲 15 分钟，或恢复会话时，提示符上方那行会自动展开成一段简短的状态摘要。

5. 想看带示例项的完整效果，运行：

```
/inbox demo
```

   再运行一次返回自己的数据。

6. 更新插件（前提：已安装过）：

```
claude plugin update inbox
```

   然后在任何已打开的会话里运行 `/reload-plugins`。

7. 前提：想从克隆的源码开发/调试时：

```sh
claude --plugin-dir /path/to/inbox
```

   改动文件后会话会自动重载该 mod。

```sh
./scripts/check.sh
```

   该脚本依次运行 Prettier、`claude plugin validate`、类型检查和测试。类型检查依赖 Claude Code 第一次加载 mod 时写入 `.claude-plugin/types/` 的类型文件。
