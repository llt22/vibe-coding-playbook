最小试用方式：

1. 挑一个可以在一次会话内完成的小型编码任务（例如给某个函数补测试前先做一遍影响面调查），先用单 Agent 做一遍，记录基线。
2. 再用主/子 Agent 分工做同类型任务：主 Agent 只负责拆解、冲突解决、跑 build/test/typecheck 和最终整合；子 Agent 只做只读探查，并按“不 build、不 test、不 typecheck；早提交、早返回”约束执行。
3. 如果子 Agent 反复卡在需要跑测试或长时间不返回，说明这条约束与你的任务不匹配，应放弃或改写，而不是加大投入。
