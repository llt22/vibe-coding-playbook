## 是什么
Scope 是微软以 MIT 许可证开源的、基于 Kubernetes 的 AI 编码智能体评测平台，用于把智能体与软件产品的交互变成可复现的实验证据。它可驱动 GitHub Copilot、Claude Code、VS Code with Copilot 等编码智能体，支持定义代表性任务、起始代码库、智能体配置、模拟用户 personas、版本化 profiles、DAG 形式的评价标准、LLM Judge、运行轨迹和工作区快照，并提供 Portal、CLI 和 REST API。它是需要自行部署的软件，不是随版本提供的托管服务。
