## 是什么

lessloc 是一个面向 AI 编码代理的开源工具层（Apache-2.0），目标是约束 Claude Code、Codex、OpenCode、GitHub Copilot、Gemini CLI、Cursor 等代理“只写满足需求的最少代码”，减少过度工程。README 声称它能让代理复用项目已有代码、拒绝占位符/注释掉的代码/零散备份文件，并在自测仍失败时回到修复。

README 给出的效果主张包括：最多减少 36% 代码、降低 26% 成本且结果相同；在 3 个开源项目的 117 个真实变更上，以隐藏测试判定，代码少 27%、成本低 23%、结果相同；每个测试项目减少 23%–36% 代码、降低成本 15%–26%。

## 具体做法（编号步骤；可直接复制的命令、配置、提示词原样放进代码块；写清每步的前提）

1. 前提：项目正在使用受支持的编码代理，并且代理能够访问 lessloc 给出的安装 URL。README 声称无需账号、API key、依赖和网络调用；但安装步骤本身要求代理访问链接，二者关系材料未展开。

2. 如果使用 Claude Code，在提示框中输入以下命令安装插件：

```
/plugin marketplace add https://get.lessloc.org/claude/lessloc.git
/plugin install lessloc@lessloc
```

3. 如果使用其他受支持代理，直接对代理说：

```
Install lessloc for this project by following https://lessloc.org/install.md
```

README 说明代理会据此完成安装并设置 hooks；npm 场景也用上面这句话安装，材料中没有给出独立的 npm 安装命令。

4. 安装后按平常方式让代理完成一个编码任务，并检查它是否复用现有代码、是否产生占位符/注释代码/备份文件，以及任务结束时自测失败是否会继续修复。README 只描述了这些行为，没有给出可复制的配置项。

5. 如需移除，对代理说：

```
Remove lessloc by following https://lessloc.org/remove.md
```

## 怎么试、怎么验证（最小试用方式和判断有没有改善的指标）

最小试用：选一个代码库和 3–5 个有代表性、带测试的编码任务；同一代理和模型下，分别跑“未安装 lessloc”的基线组和“安装 lessloc”的试验组，任务顺序可交替以减少偏差。先在一名开发者、一个项目内试用，不要一开始全团队铺开。

记录指标：新增/删除代码行数、改动文件数、token 或成本、测试通过率、review 评论数、返工次数、是否出现占位符/注释代码/备份文件、任务完成时间。重点看“测试结果不下降”的前提下，代码量和成本是否下降。

判断改善：同一任务测试通过率不低于基线；代码改动量中位数明显下降（可先以 15% 作为观察阈值）；成本不高于基线；review 没有因代码过少而增加返工。若测试通过率下降或 review 返工明显增加，应停用或仅保留为研究项。
