## 怎么试、怎么验证（最小试用方式和判断有没有改善的指标）

**最小试用（两周起步，单仓库、单档位）**

1. 选一个 CI 稳定、可快速回滚的仓库，**只划一条最保守的低风险白名单**（例如：仅文档、注释、测试文件、格式化改动）。
2. 前置条件必须齐备：CI 必过 + 安全扫描必过 + 有自动 revert 能力；任一不满足则该档位不开启。
3. 开启该档位的免人工合并，**其余 PR 流程完全不动**，形成同仓库内天然对照组。
4. 保留人工抽检：对自动合并的 PR 每周随机抽若干条由人复核，记录"本应被拦下"的比例。
5. 设定熔断规则（建议事先书面写死）：一旦周回滚率超过基线，立即关闭该档位。

**判断有没有改善的指标**

| 维度 | 指标 | 期望方向 |
|---|---|---|
| 吞吐 | PR 合并周期（open→merge 中位时长）、单位时间合并数 | 下降 / 上升 |
| 质量代价 | 回滚率（revert 占比）、低风险档位的线上事故数 | 不上升（这是底线） |
| 门禁有效性 | 人工抽检中"本应拦下"的比例 | 接近 0 |
| 人力转移 | 人工审批耗时占比、评审人力转向非低风险 PR 的比例 | 下降 / 上升 |

**结论口径**：只有当"合并周期明显缩短"**且**"回滚率不高于基线"同时成立，才算改善；若吞吐上升但回滚率同步上升，说明低风险边界划得过宽，应收窄白名单而不是放弃机制。
