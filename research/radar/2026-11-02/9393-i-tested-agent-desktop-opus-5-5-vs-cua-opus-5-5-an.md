## 怎么试、怎么验证

**最小试用方式**（半天量级）：
- 选 10 个任务：4 个离散动作（本就该成功，用来确认环境配置正确）、3 个空间精细操作、3 个长列表定位。
- 用 cua 和 codex computer use 各跑一遍，agent-desktop 可选。
- 每个任务写一句可观察终态，跑完逐条打勾。

**判断有没有改善的指标**：
1. **任务完成率**：与你现在的人工耗时做对比，而不是只和别的 agent 比。关键问题是“这几个任务交出去之后，我省下的时间是否大于检查与返工的时间”。
2. **空间类任务失败率**：如果 3 个空间精细任务里失败 ≥2 个（与原文方向一致），就在流程里把这类操作永久划为人工或走 API。
3. **返工成本**：记录每次 agent 完成但结果需要人工修正的比例——原文的“完成数”没有覆盖这一项，而它往往决定实际是否省事。
4. **稳定性**：同一任务跑 3 次，看是否 3 次都成功；只成功 1 次的任务不能写进常规流程。

达到“10 个任务里 ≥8 个一次成功且无需返工”再考虑纳入日常工作流；否则停留在试验阶段，等工具版本更新后重测。
