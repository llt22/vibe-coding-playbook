4. 记录过程数据（人工介入次数、返工次数、总耗时、token/额度消耗）。

**判断改善的指标**
- **完成率**：子任务一次通过的比例（B 组相对 A 组是否不降）；
- **人工介入次数**：需要人手动拆任务、粘贴上下文、合并结果的次数是否下降；
- **总耗时**：端到端时间对比；
- **冲突/重复率**：子任务之间改同一处代码、给出矛盾结论的比例；
- **上下文一致性**：长对话累积后，后段任务是否仍遵守早期约定（这是“长期对话”结构最需要验证的风险点）；
- **额度成本**：多 agent 并行是否显著抬高消耗。

**淘汰条件**：若冲突/重复率明显高于串行组，或人工介入次数并未减少（说明协调者没有真正承担拆解工作），则说明该结构对这类任务不成立，应退回单会话做法。
