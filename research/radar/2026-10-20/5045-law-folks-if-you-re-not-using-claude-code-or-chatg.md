## 怎么试、怎么验证

最小试用（在取回技能包之后）：

1. 选一篇自己已定稿、引注已人工核对过的文稿（建议 20–50 条引注）作为对照样本，人工核对结果作为金标准。
2. 在 Claude Code 中装入 cite-checking 技能，对同一样本运行一遍，逐条比对：漏检的错误、误报的「错误」、给出的出处是否真实存在。
3. 单独跑 proofreading 技能，记录每条改动是否被采纳（采纳率）以及是否改坏了原意。
4. 换 Codex 用同一技能重跑，比较两者在漏检与误报上的差异。

判断是否改善的指标：

- 引注错误检出率（召回）与误报率（精确）——误报高会让人放弃使用，比召回更关键；
- 引注查找给出的出处可验证率（是否存在、是否对得上页码/段落）；
- 校对建议采纳率与「改坏」条数；
- 单篇文稿的净耗时（含人工复核时间），必须计入复核成本，否则改善是假的；
- 与「不用技能、直接向通用模型提问」这一基线的对比，避免把模型本身的能力误算成技能包的功劳。
