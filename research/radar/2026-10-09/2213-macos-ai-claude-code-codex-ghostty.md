## 是什么

GhosttyEXTREME 是 Ghostty 1.3.1 的一个 macOS 分支。按推文说法，它针对“在 macOS 上同时跑多个 AI 编码代理（Claude Code、Codex 等）”这一场景，补上原版 Ghostty 看不到的东西，具体列出四项能力：

- 侧边栏：展示各个编码代理的实时状态
- 跟随编辑的代码编辑器 + 代码地图（code map）
- 权限应答（agent 请求权限时在终端内处理）
- 回合撤销（撤销某一轮 agent 改动）与变更审查

本质上是把“多个 CLI 代理并行跑”的状态观测、审批与回滚集中到一个终端窗口里，而不是给代理本身加能力。
