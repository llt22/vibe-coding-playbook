## 是什么

oar（Open Agent Runtime）是 GitHub 上 botiverse 组织下的一个项目，推文将其描述为“所有 agent harness 的编程接口”（programming interface for all agent harnesses）。作者推荐它的场景是：不喜欢 ACP，但又想调用多种 agent（原文列举 Claude Code、Codex、Kimi Code、Pi 等）。

作者给出的设计思路类比是 @xuanwo 的 OpenDAL：与其做一个协议层（如 S3-compatible）去对接各种不同服务——作者认为这样“总会有很多坑”——不如做成一个 library，因为做成 library “可以做更多事”。

也就是说，oar 的定位是：用统一的库级调用接口，把多个 agent harness 抽象成可替换的组件，而不是定义一套跨实现的通信协议。
