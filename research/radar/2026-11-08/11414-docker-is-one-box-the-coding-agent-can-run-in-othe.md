4. 每个后端跑同一批任务，重复多次以抵消随机性。

判断指标：

- **切换成本**：改配置实际需要改几处、几行；是否需要改业务代码（预期为 0 才算达成主张）。
- **任务成功率**：同一批任务通过测试的比例，跨后端是否一致——若不一致，说明“同一套工具”并不等价，选型必须按任务分。
- **环境启动时延与单任务耗时**：本机容器/microVM 与云端的差异。
- **单任务成本**：云端后端的计费对比本机资源占用。
- **隔离与安全**：agent 执行的代码能否触及宿主机文件、网络、凭据——这决定哪类任务只能放 microVM 或云端。
- **失败可诊断性**：环境出错时日志与错误信息是否足够定位。

判定标准：只有在“切换确实≤1 处改动”且“成功率不因后端下降”同时成立时，才值得把这条写进手册的选型章节；否则降级为“执行环境应可插拔”的设计参考。
