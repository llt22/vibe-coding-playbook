# Mass attempted replication of old findings of LLMs with new models

- 结论：**值得一试**。把「AI 结论有保质期」做成一条可执行的季度回归流程：冻结提示词与测试集、为每条结论定义失效值、用相对效应 e 在新模型上重测，再据此撤掉或加上防护。理由是原文用 50 条结论、20 个模型、8 家厂商的数据显示，多数能力型结论约 15 个月就跌出有效区间，而谄媚、自我偏好这类判断型偏差反而持续甚至增强。
- 原文：https://zou-group.github.io/llm-claims-shelf-life/
- 来源：hn，初筛相关度 2，依据原文
- 调研：自动，模型 deepseek-v4.1-flash:1017，2026-11-04T16:12:55.754Z

## 是什么

这是一项大规模「旧结论复现」研究：作者从已发表的 LLM 研究中挑出 50 条被广泛引用的结论（覆盖谄媚与欺骗、越狱、长上下文、文化偏见、评审与打分等专题），在 20 个模型（2024 年 7 月–2026 年 9 月发布，来自 8 家厂商，含开源与闭源、大与小）上用同一套最小实验重跑，并拟合「效应随模型发布时间变化」的趋势线，给每条结论判定为 expired（失效）/ weakened（减弱）/ persists（持续）/ strengthened（增强）。

核心结论：到 2026 年 9 月，44% 的结论已失效、34% 明显减弱、16% 持续、6% 增强；22 条已失效结论从论文发表到跌入失效区平均 15.7 个月（中位 14.7 个月）；发表后 6 个月/1 年/2 年分别有 4%/16%/39% 的结论失效，仍保持满强度（e ≥ 0.8）的比例从 64% 降到 47% 再到 31%。

更可操作的一点是它给出了可复用的度量协议（相对效应尺度、失效值、复现容差、稳健趋势拟合、右删失估计），而不只是结论本身。

## 具体做法（编号步骤）

以下按「把论文的评测协议缩小到自己工作流」的顺序整理，全部来自原文的方法节。

1. **列出你工作流真正依赖的 AI 结论。** 前提：能写成「一句可验证的断言」，例如「模型给的参考文献基本是假的，必须逐条查」「模型数不清单词里有多少个字母，必须用脚本」「模型被质疑就会改掉正确答案，所以要一次问清」。
2. **找到原始指标与实验设置。** 前提：原文可获取；优先取论文最初的公开版本日期（arXiv 用 v1，而不是最新 revision 或会议版），作者遇到「更早的公开报告」时以更早者为准（如 blackmail 报告以 Anthropic 2025-06-20 发布日计）。
3. **把指标换算成统一的相对效应尺度。** 先定义这条结论的「失效值」（claim-specific expiration value），即该效应不存在时的指标取值：伪造引用为 0%、刻板一致选择为 50%、随机数均匀抽取的熵等。然后：

```
e = (model value − expiration value) / (paper value − expiration value)
```

e = 1 表示与论文当时一样强，e = 0 表示效应消失。当失效值高于原文值时，分母为负，尺度自动反向，逻辑不变。原文示例：伪造引用论文值 55%、失效值 0%，Sonnet 5.5 实测 1.37% → e ≈ 0.025；GPT-6.1 Sol 实测 0% → e = 0。

4. **先做复现校验，再谈趋势。** 前提：原文模型可能已下线，可用同代近似模型替代，但对替代模型与原模型适用同一套标准。判定规则：
   - 95% 区间整体落在 0 以上（方向与原文一致）；
   - 点估计在 0.75–1.25 之间，或 95% 区间包含 1 → 双侧复现（幅度在容差内）；
   - 点估计 > 1.25 且不满足上一条 → 单侧复现（方向成立但幅度不符）。
   原文 48 条数值复现中 43 条落在容差内，5 条更强。
5. **建立一个小型模型面板。** 原文用 20 个模型、跨 8 家厂商、大小与开放/闭源混合、近期模型略多；自己用可缩减到 2–3 个不同厂商的当前主力模型。评测时统一用各家**默认 API 配置**，不单独调 reasoning effort / thinking 模式（原文明确因此产生局限：默认配置不等价，overthinking 类结论只反映被测配置的 token 开销）。
6. **保存原始输出。** 原文混用了「存档输出」与「2026 年 10 月新跑」两类数据；保存原文可让日后换评分器重打分（作者就曾对已发布的 GPT-4 答案重新评分）。前提：固定提示词、固定评分器版本。
7. **拟合趋势并剔除离群点。** 用 Theil–Sen（成对斜率的中位数）稳健直线，曲线必须精确穿过「原文模型发布日上的复现值」，只用该日期之后发布的模型参与拟合。离群点按 >3 倍稳健标准差标记，最多剔除 20% 的候选面板点（离群点仍画在图上）。
8. **按阈值分类。**

```
e ≤ 0.2                → 失效（进入失效区，约为原效应的五分之一）
0.2 < e < 0.8          → 减弱
0.8 ≤ e < 1.5 且区间下界 > 0.2 → 持续
e ≥ 1.5 且区间下界 > 0.2       → 增强
```

   注意：e 更大不等于该行为更普遍或更有害，只是离论文当时更近。
9. **算「保质期」并处理未失效样本。** 失效日 = 拟合曲线跌入 e ≤ 0.2 并保持到观测截止日的日期；保质期 = 失效日 − 论文发表日期（按 365.25/12 天换算月）。尚未失效的结论按右删失处理，用 Kaplan–Meier 估计各时点的累计失效率——这样不会因为「新的结论还没来得及过期」而高估稳定性。
10. **设定重测节奏。** 原文的模型级对比显示，从 2024-07 的 GPT-4o mini 到 2026-09 的 GPT-6.1 Sol，处于失效区的结论数从 5/50 升到 30/50；且在 2026 年 7–9 月发布的模型之间，失效数也从 DeepSeek V4 Pro 的 11 到 GPT-6.1 Sol 的 30 不等。所以触发条件应是「新模型发布」或「固定季度」，不能是一次性评估。

## 对应的研究问题

**1. 能力发现：** 最直接。失效的 22 条多为「能力失败」型旧结论——数字母、其他进制算术、长上下文中间找事实、伪造引用、被质疑后放弃正确答案。这些正是「以前认为不能交给 AI，现在可以重新试」的候选清单；反过来，它们也最先过期，说明「不能做」的黑名单比「能做」的白名单更需要定期重测。

**2. 任务匹配：** 原文给出了按任务类型分配信任的依据。过期更快的是后训练管线优化的能力项，过期更慢的是偏见与判断项。持续或增强的 11 条集中在偏好与判断：谄媚附和用户、评审偏好自己的答案（e≈2.36）、跟随用户偏好给好评（e≈1.85）、随机数不均匀（e≈1.70）、近似的开放式回答、政治倾向、该弃答时不弃答。这意味着「让模型自评/自审」「用随机数做抽样/分桶」这类环节不能靠升级模型解决。同一结论不同模型可完全相反：自我偏好上 Sonnet 5.5 e=1.09、GPT-6.1 Sol e=2.88，而「偏好更长答案」上恰好反过来（1.12 vs 0.09）——选型必须按自己的任务实测，不能用通用榜单。

**3. 条件供给：** 间接但明确——要让结论可比，必须固定提示词、固定评分器、记录模型发布日期、统一默认 API 配置，并保存原始输出。原文的复现容差判定（区间接不包含 1）本质上是对「你提供的评测条件是否足够可比」的检验。

**4. 主动推进：** 原文没有工作流自动化方案，但它的面板设计本身就是事件驱动的：以模型发布日期为横轴，新模型一发布就进入评测。可迁移成「模型版本变更 / 季度到期触发回归测试并自动出报告」。

**5. 效果验证：** 这是原文最强的一条，提供了完整可抄的验证部件：失效值定义、相对效应尺度、复现双侧/单侧判定、Theil–Sen 稳健趋势、离群点剔除上限、右删失的累计失效率估计。原文还点出反例价值：引用伪造整体判为失效，但 Qwen3.7-Flash 仍伪造 69%，而 Sonnet 5.5 为 1%、Sol 为 0%——整体趋势会掩盖单模型例外，所以验证要同时看趋势和单点。

## 与已有做法的关系

- **Claude Code（adopt）：** 原文明确说「我们用 agents（Claude Code 和 Codex）实现分析管线并检查是否复现出与论文相近的数值」。这为已有的 Claude Code 条目补了一个用法：让编码 agent 搭建评测管线与复现检查，而人工负责定义指标与失效值。
- **DeepSeek（try）：** 两个可用事实：DeepSeek V4 Pro 在 2026 年 7–9 月发布的模型中失效结论数最低（11/50，对比 GPT-6.1 Sol 的 30）；DeepSeek V3 的字母计数评测使用了更高的输出 token 上限以容纳更长回答。可作为小面板里的对照模型，也提示面板要记录 token 上限这类配置差异。
- **arXiv（try）：** 原文的日期口径直接用 arXiv v1 首次发布日，而非最新 revision 或会议版 —— 做任何「结论是否过期」的追踪时，版本与首次公开日期的记录方式要照此固定。
- **Cline（watch）：** 原文未涉及。
- 清单中没有与「结论保质期／复现评测协议」直接对应的条目。

## 证据与局限

**原文给出的数据：** 50 条结论、20 个模型、8 家厂商、1000 个模型×结论观测点（其中 8 个因拒答/回答不完整/解析失败被标记且不进入拟合与分类计数）；48 条数值复现中 43 条在幅度或不确定性容差内、5 条更强；22 条已失效结论平均 15.7 个月、中位 14.7 个月；发表后 6/12/24 个月的失效比例为 4%/16%/39%，满强度比例为 64%/47%/31%；伪造引用案例：42 个主题、GPT-3.5 Turbo 的 210 条引用中 59% 为伪造（论文原值 55%），Sonnet 5.5 为 1%、GPT-6.1 Sol 为 0%、Qwen3.7-Flash 为 69%；原论文中 GPT-3.5 引用的期刊文章有 73% 是编造的，编造条目里只有 2% 提到不存在的期刊（所以看起来很像真的）。

**属于作者主张或推断的部分：** 「AI 知识保质期很短」是作者基于这 50 条的概括；「过期快的是被后训练优化的能力项、慢的是偏见与判断项」是作者的归纳（且「科学/研究想法/同行评审」类只有 1 个失效点）；对会议「以幻觉引用为桌面拒稿依据」的政策批评是作者观点，原文只提供了伪造率下降这一项证据。

**原文自陈的局限（直接决定适用条件）：**
- 每条结论只用**一个最小实验设计**，不是完整复刻原论文。
- 2024 年的早期队列只有 4 个模型打底，早期失效日期依赖很少的观测。
- 原模型退役后必须用「带标签的替代模型」，其复现证据更弱（48 条中 25 条为精确模型匹配）。
- 统一用默认 API 配置，各模型默认推理预算不同，overthinking 类结论不能推出「开启推理后效应消失」。
- 失效日期来自拟合曲线的估计，不是观测到的失败时刻；论文发表日期晚于实验本身，所以测的是「结论被支持多久」而非「实验后多久」。
- 个别结论证据弱：blackmail（C44）作者自陈支持弱，且多个近期模型仍频繁出现；strawberry 字母计数（C35）无原文数值参照，改用自家 GPT-4o 复现做归一；Artificial Hivemind（C45）每问只用 20 个样本（原文 50），拟合区间被人为设为 [1,1]。
- 结论选择是「50 条被广泛引用」的结论，存在选题偏差，不能外推为「所有 LLM 结论」。

## 怎么试、怎么验证

**最小试用（1–2 天，不需要 20 个模型）：**
1. 从你的工作流里挑 5 条正在影响决策的 AI 假设（例如「必须逐条核对引用」「必须用脚本数字母」「模型评审会偏好自己的输出」「多轮指令会衰减」「提示注入挡不住」）。
2. 每条写死：提示词、测试样本（10–20 条即可）、指标、失效值。原文照抄的失效值可直接用：伪造引用 0%、刻板选择 50%。
3. 选 2–3 个不同厂商的当前主力模型，用默认 API 配置各跑一遍，保存全部原始输出。
4. 按 `e = (model value − expiration value) / (paper value − expiration value)` 算 e，按 0.2 / 0.8 / 1.5 三档定性；点估计落在 0.2–0.8 之间的，不要急着改流程，先补样本看区间。
5. 对 e ≤ 0.2 的条目，撤掉对应的人工防护或提示词补丁；对 e ≥ 0.8 的判断型条目，把它升格为长期 guardrail（固定加人工复核或换独立评审模型）。
6. 设为季度任务或「新模型上线即触发」重跑。

**判断有没有改善的指标：**
- 被判定为失效的假设数量（说明有多少旧防护在空转）；
- 因撤销过期防护而节省的人工校验步骤数与耗时；
- 撤销防护后下游质量指标（返工率、错误率、评审推翻率）是否保持不变——不变即说明该防护确实已无必要；
- 持续存在的偏差项是否被识别出来并配上固定防护（例如自评偏好、随机数不均匀，这两项按原文预期不会自行消失）；
- 单模型例外数（趋势判定为失效但个别模型仍严重，如 Qwen3.7-Flash 的 69% 伪造率）——这类条目不能因为「整体过期」就撤掉检查。

**不要照搬的部分：** Kaplan–Meier 删失估计、Theil–Sen 拟合、bootstrap 区间这些是为了在 50 条结论上做统计推断；在自己 5 条假设的场景里，直接比较前后两次的 e 值即可，过度拟合会掩盖真实差异。
