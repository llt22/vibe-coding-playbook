## 怎么试、怎么验证

**最小试用方式（在补齐上文 1–6 项信息之后）：**

1. 选一个**低风险、可回滚**的任务类型作为试验田，例如：在一个独立分支上做小改动、跑测试并汇总失败原因。不要一上来就给推送权限或外部发送权限。
2. 先跑“影子模式”：让它照常判断和行动，但所有卡片都强制由人确认，记录它**认为不需要问人**的那些动作清单，人工审核这批动作里有多少是不该放行的。这一步是判断它靠不靠谱的关键。
3. 影子模式无误后，再对白名单内的动作放开自动执行，其余仍走卡片。
4. 连续跑一周同类任务，保持人工审核记录，再决定是否扩大范围。

**判断有没有改善的指标：**

- 人工介入次数 / 任务数（应下降，但不能以漏判危险动作为代价）；
- **漏判率**：它自行放行但事后被人判定为“本该问”的动作占比（这是否决性指标，比介入次数更重要）；
- 误报率：它弹卡片问人、但其实完全无需确认的占比（太高就等于没省事）；
- 任务一次跑完的比例，以及失败后能自行恢复的比例；
- 端到端完成时间与人工盯屏时间的对比（相对于不用它的基线）；
- 回滚/返工次数。

只有在“人工介入明显下降 + 漏判率接近零”同时成立时，才能认为这个模式确实改善了工作方式。
