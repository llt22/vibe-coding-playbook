## 怎么试、怎么验证

**最小试用（前提：先从仓库 README 确认可部署，并用隔离环境）**

1. 用独立浏览器 profile 或专用小号登录，不用主账号、不在装有敏感资料的主力机上跑。
2. 只授权**一个低风险站点**，只派**一个只读型任务**，例如“打开某列表页，把前 20 条标题抄成文本”。
3. 全程在手机上旁观，记录字幕与实际动作是否对得上；遇到第一次可疑动作就接管。
4. 连续做 5 次同样的任务，再换 1 个稍复杂的（需要点击翻页或多步进入详情）。

**判断有没有改善的指标**

- 任务完成率（5 次中成功几次，失败是模型不会用界面还是环境问题）；
- **人工接管次数与接管时点**——接管越少且越晚，说明字幕的“可判断性”越好；
- **字幕与实际动作的一致率**（抽查每一步，尤其是有提交/跳转的步骤）；
- 危险动作计数，应为 0（未预期的表单提交、删除、跳转支付）；
- 与手工完成同一任务的耗时对比（含监督时间，不要只算 agent 执行时间）。

**放行/淘汰标准**

- 若能在隔离环境下稳定完成单一低风险只读任务、且字幕足以让人判断何时该拦，可以升级为“值得小范围试”，并补上部署步骤与权限边界后写进手册；
- 若两次配置内无法跑通，或字幕与实际动作频繁不符（监督失效），则维持 watch/drop，只保留“手机端逐步字幕 + 随时接管”这个设计点作为手册里“给 agent 浏览器权限时的监督形态”参考。
