**最小试用方式（只依赖有依据的那一步）：**

1. 选 2–3 个规模相近、你本来就打算交给 Claude Code 的小任务（半天以内能完成的那种）。
2. 对照组：直接开对话，用你平常的 Prompt 方式做。

4. 两组都记录下文四个指标，任务完成后回填。

**判断有没有改善的指标：**

- **澄清轮次**：Agent 在动手前追问需求/目标的次数（实验组应更少）。
- **返工量**：因“理解错产品目标”导致的返工 diff 行数或重写次数。
- **方向性偏差**：首次提交是否朝目标功能推进，还是做成了别的东西。
- **人工复述成本**：你为解释背景而重复打字的时间（粗略计时即可）。

**判定标准建议**：如果实验组在 2–3 个任务上稳定减少澄清轮次和方向性偏差，则说明“先写 PRD.md”这一步值得固定下来；如果差异不明显，则说明单靠一份 PRD 不足以复现作者的效果，需要先补齐其余五份文件再重测——这也正是当前不建议直接 adopt 的原因。
