## 怎么试、怎么验证

最小试用方式（需先完成“具体做法”第 2 步，确认口径后才能执行）：

1. 取自己工作里一组**小而明确、有客观正确性判据**的任务（10~30 个即可），构成自建任务集。
2. 在同一模型下，分别用 Forge 与 Claude Code 跑同一任务集，保持提示词与工具权限一致，记录每次运行的 token/费用与是否解决。
3. 计算并对比三个指标：
   - **每解决任务成本** = 总花费 ÷ 成功解决数（失败任务的成本也要计入，否则成本会被低估）。
   - **解决率** = 成功解决数 ÷ 总任务数。
   - **成本与解决率的组合判断**：只有当解决率不下降（或下降幅度可接受）且每解决任务成本明显下降时，才算改善。若像原文那样“便宜 49% 但少解决 5/290”，需自行权衡是否值得。
4. 判断有没有改善：以自建任务集上的每解决任务成本和解决率与 Claude Code 基线做配对比较；差异小于任务集规模带来的波动时，视为无改善。
