## 怎么试、怎么验证（最小试用方式和判断有没有改善的指标）

本条的“试用”本质上是**复现和口径核对**，不是引入新工具：

1. 前提：先拿到官方仓库与任务集（当前材料未提供，需另行确认；拿不到则本条止步于 study）。
2. 固定模型与权重版本、推理参数、任务集版本、预算上限。
3. 在同一任务集上至少跑两个 harness（例如 Mini-SWE-Agent 与 Claude Code）。
4. 每个配置重复多次（多 seed 或多轮），记录每次结果，而不是只记最好一次。
5. 对照原文的 62%，看能否在相同口径下复现。

判断有没有改善的指标：

- **通过率之差**：同一模型在不同 harness 下的差值，即原文主张的“harness 效应”大小。
- **方差**：重复运行之间的波动；如果方差大于 harness 差值，则 harness 效应不可信。
- **单位任务成本**：token 消耗、耗时、调用次数。
- **失败模式分类**：差在“不会做”还是“脚手架没给对反馈”，这决定改模型还是改 harness。
- **可复现性**：原文数字能否被复现；不能复现则视为不可采用，仅保留“harness 是变量”这一研究假设。
