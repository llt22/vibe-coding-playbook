## 具体做法

前提：你在一个 git 仓库里工作（「工作树」即 worktree，是 git 的概念），并且确实有多个代理要同时改同一份代码。

1. 进入项目的 git 仓库目录。
2. 用下面的命令启动 Claude Code：

```
claude --worktree
```

3. 对每个要并行的代理重复第 2 步，让它们各自在自己的副本上编辑，而不是争抢同一个工作树。
4. 主工作树保持不变，由人掌握，代理不直接触碰它。
