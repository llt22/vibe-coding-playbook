## 是什么

Agent Cockpit 是一个面向“用 AI agent 做研究”的构建者的本地白板 + MCP 服务器。它要解决的问题写在标题里：agent 改了代码之后，昨天的实验结果还成不成立。

按原文描述，它把“结论（claim）”绑定到“被记录过的实验运行”和“该次运行所依赖的代码”上；代码变更后，用内容哈希把过期的运行及其下游结论在板上标出来。原文列出的功能有：

- 可追溯证据：每条结论引用某个已记录运行的输出文件中的一个具体值
- 变更检测：内容哈希标记过期运行与依赖它们的结论；代码回退后哈希重新匹配，标记解除
- MCP 集成：Claude Code、Codex、Cursor、Gemini CLI 可连到同一块研究板
- 人工决策：agent 可以请求输入并等待；证据链断裂会触发一个决策请求和一份证据摘要
- 会话回放：append-only 事件日志，可拖动查看板的历史状态

开源，AGPL-3.0-or-later。

**判断有没有改善的指标**：

- 结论可追溯率：被引用的结论中，能指到具体运行和具体数值的比例（试用前 vs 试用后）。
- 过期结论的提前发现次数：在有人踩坑之前被标红的次数。
- 误报率：被标红但复查后结论依然成立的比例——这一项高说明哈希口径太粗，需要收窄到关键文件。
- 从代码变更到人注意到的时间差。
- 复查一条标红结论的平均耗时（判断证据摘要是否真的省事）。
