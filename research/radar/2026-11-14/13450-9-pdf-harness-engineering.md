## 是什么

一条 X 推文（@gimcall），转述“谷歌最近出了一份 9 页 PDF 讲 Harness Engineering”，并给出核心公式：

```
Agent = Model + Harness
```

推文把 Harness 拆成六类组件，各配一句话：

| 组件 | 推文原话要点 |
|---|---|
| Guides | 给 Agent 立规矩，把以前踩过的坑记录下来，别再犯 |
| Sensors | 测试、Linter、验证工具，检查每一步输出，别让错误一路传下去 |
| Agentic Loop | 先规划、再执行、检查结果、不对就改；要有限额，必要时让人接管 |
| External Memory | 把决策、项目进度、开会讨论过的结果存到模型外面，避免换上下文就忘 |
| Permissions | 规定哪些工具能用、哪些操作不能自己做 |
| Observability | 做了什么、花了多少钱、哪里报错、重试了几次，都要能查 |

后半段还提到两件事：一是 “Graph Engineering”——4 个 Agent（研究/分析/写代码/检查）各自带 Harness，其中一个失败可作为信号让其他 Agent 调整后续执行；二是 Hermes，被描述为 “Agent 的工作环境，工具、Skills、记忆、工作流程都在里面”。

另附 4 个开源项目名：Google Harness²、Learn Harness Engineering、Awesome Agent Harness、Harness Engineering，链接均为被换行截断的 t.co 短链，卡片显示指向 `github.com/google-research/harness2`。
