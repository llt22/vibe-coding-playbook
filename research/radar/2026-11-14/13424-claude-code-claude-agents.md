4. 同一批任务再用串行方式（单个会话依次做）跑一遍作为基线。

**判断有没有改善的指标：**

- 三个任务的总实际耗时（并行 vs 串行基线）；
- 每个任务的人工介入次数——若并行后介入次数显著上升，说明任务拆分或信息供给不到位，而非工具问题；
- Worktree 合并/冲突次数与解决耗时，这是并行方案的隐性成本；
- 任务一次通过率（是否需要返工重做）；
- 主观项：面板三态是否足以判断“该我出手了”，还是仍要逐个进去看。
