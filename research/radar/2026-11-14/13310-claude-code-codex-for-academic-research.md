## 怎么试、怎么验证

最小试用方式：先获取仓库 README 和示例，按官方说明在隔离环境跑通；选 3 至 5 篇公开论文，固定输入，和“单 Agent 评审”或“人工快速评审”做对照。若仓库无法跑通，就停留在 study，不进入手册。

验证指标建议预先设定：

- 真实问题召回率：多 Agent 是否找到基线漏掉的有效问题。
- 误报率：是否大量生成不成立或不可执行的评审意见。
- 可执行性：由 1 至 2 名研究者盲评意见是否具体、可修改。
- 一致性：同一论文重复运行时结论是否稳定。
- 成本与时间：token 费用、运行时长、人工复核时间。
- 与人工评审的重合度：是否补充而非重复人工意见。

判断改善的标准不是“看起来更全面”，而是在误报和成本可接受的前提下，真实问题召回率或意见可执行性优于基线。
