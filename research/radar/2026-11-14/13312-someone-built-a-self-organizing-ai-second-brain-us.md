## 是什么

claude-obsidian 是 Daniel Agrici 做的一个项目，用 Obsidian + Claude Code 构建可自我组织的 AI 第二大脑。按推文描述，它能把论文、文章、转录稿或自己的笔记转成互相链接的 Markdown 笔记，连接成知识图谱，并支持从笔记中带引用回答问题、按请求保存有用洞察、检测坏链、孤儿页和缺失元数据。所有内容都留在 Obsidian vault 中，可通过 Graph view、Canvas 或 Claude Code 浏览。

其关键不是“生成笔记”，而是写入安全：使用 15 个 Agent Skill 组织知识工作流，设置 3 个只读 Agent 分别负责摄取、校验和维护，用 SHA-256 哈希检测冲突编辑，并用事务层控制写入和失败恢复。Agent 可以提出变更，但只有事务层能修改 vault。
