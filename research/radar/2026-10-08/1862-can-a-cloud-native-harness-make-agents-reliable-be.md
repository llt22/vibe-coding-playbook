## 是什么

这是 Latent Space 的一篇访谈式报道，介绍 Stacklok 的“cloud-native harness” Mecatl，以及配套的 ToolHive 和 AI Gateway。Stacklok 由 Kubernetes 联合创始人 Craig McLuckie 和 Joe Beda 创办（2023 年 1750 万美元 A 轮，Accel/Madrona/Bain Capital），最初做软件供应链安全，后转向基于 Kubernetes 的 agent 基础设施。

核心主张：现有 coding agent harness（Claude Code、Codex、GitHub Copilot 等）大多是桌面优先架构——agent loop、本地执行、会话状态常常起在同一个进程里，即使有插件机制，仍然是“为桌面而生的一个进程或一组紧耦合进程”。Mecatl 想把这套东西按云原生方式重新设计，把“价值所在从桌面搬到云端”。

Mecatl 是 2026 年 6 月起在 GitHub 上的开源项目；ToolHive 是开源 MCP 服务器运行与治理平台；AI Gateway（LLM 网关）尚未开源，官网说是“在路线图上”。商业产品是“enterprise spine”——把开源组件串起来的控制平面，提供统一身份、授权、策略与审计。
