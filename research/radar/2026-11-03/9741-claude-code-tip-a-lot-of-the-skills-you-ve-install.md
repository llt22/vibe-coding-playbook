## 怎么试、怎么验证

**最小试用方式（自建，原文未给）：**

1. 从你当前已装的技能里挑 1–3 个你最不确定其价值的，不要一次性全测。
2. 为每个技能准备 3–5 个你真实工作里会重复出现的任务，写成固定的提示词清单。
3. 同一任务各跑两次：一次移除该技能，一次保留该技能；尽量在相近时间、相近上下文长度下进行，避免其他变量干扰。
4. 记录四项指标：结果是否正确/可直接使用、需要你改写或返工的次数、单位任务耗时、是否出现该技能本应避免的错误。
5. 若连续多个任务上两组无差异，卸载该技能；若有差异，保留并记下它在哪类任务上起作用。

**判断“有没有改善”的指标：**

- 有效差异率：在测试任务中，装技能组明显优于不装组的比例（低于阈值即视为无价值）。
- 返工次数与人工干预次数：这是比“看起来更专业”更硬的信号。
- 上下文成本：技能本身占用的上下文是否挤占了任务本身的空间（可通过对比长任务表现间接观察）。
- 稳定性：同一任务重复运行时，两组结果方差是否变化——技能若只是让输出变得更啰嗦而无实质提升，应判为无差异。
