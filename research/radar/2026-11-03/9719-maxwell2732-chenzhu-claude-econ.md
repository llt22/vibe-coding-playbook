## 是什么

这是朱晨（中国农业大学经管学院）免费开放的 6 次课课程仓库，主题是 **用 Claude Code（或 Codex）做经济学研究**：从数据采集清理、计量分析、论文复现、理论建模到写作，要求每一步留下证据（表和图由脚本生成、数据处理有记录、关键数字独立核对）。

- 形式：6 次课，每次约 2 小时，5 次实操 + 1 次研讨；面向博士生、高年级硕士、青年教师。
- 每课资料结构固定：**讲义 PDF → 图文作业说明 PDF → 作业包 zip（可在网页直接浏览）→ 验收清单**。

2. **装环境（第 1 课作业说明里有图文步骤）**：Claude Code（或 Codex）、Python 或 Stata、Git。
3. **立刻申请数据（有时间成本，要提前做）**：第 3、4 课要用 CHNS 或 CHARLS，按各数据官网流程自行申请，可能需要几天到几周。课程不分发数据，授权数据不得分享、不得上传公开仓库。
4. **固定资料使用顺序**：讲义 → 图文操作说明 → 作业包 → 验收清单自查。第一次用终端的先看作业说明。
5. **第 1 课**：写自己的 `CLAUDE.md`（项目上下文约定），用 Plan mode 完成一个小任务，并按验收清单核对结果。
6. **第 2 课**：从空文件夹到一张可用于论文的图。两条路径：用公开数据接口下载世界银行数据；或用智能体操作浏览器采集小红书评论（**人扫码登录**，人机分工）。社媒数据只能用于个人学习研究，遵守平台协议、控制采集频率、个人信息去标识化、原始数据不公开。
7. **第 3 课**：用作者的 research harness 清理 CHNS，产出三件东西——审查报告、清理后的面板、带变量定义的 codebook。
8. **第 4 课**：跑 CHARLS 长护险 staggered DID；复现一篇论文；专门练习“用大模型构造变量时怎样验证”；并**写自己的第一个 `SKILL.md`**（把可复用流程固化成技能）。
9. **第 5 课**：用 pAI-Econ 构建理论模型；按作者自己的论文写作顺序写作；**新开会话做审稿**（用干净上下文审自己的稿，避免自我确认）。
10. **第 5 课综合作业（二选一）**：交付“别人能重跑的复制包”，或交付“一节理论机制”。这是整个课程最硬的验收物。
11. **第 6 课（研讨）**：AI for Social Science 的验证问题、Project APE 与 HLER 案例、智能体常见的八种错误、研究者的训练。
12. **改用 Codex 的适配（前提：已装 Codex）**：让它读取课程按 Claude Code 组织的 `CLAUDE.md` 与 `.claude/skills/`，自动生成对应的 `AGENTS.md`，提示词在 lab1 作业包的 `codex_adapt_prompt.md` 里。
13. **Codex 联网配置（前提：下载数据的脚本需要联网）**：Codex 默认沙箱不允许终端命令联网，Windows 上会报 `WinError 10013`。在 `~/.codex/config.toml` 加：

```toml
[sandbox_workspace_write]
network_access = true
```

    改完重启 Codex。
14. **国内工具**：Trae 桌面版可在设置中打开对 `CLAUDE.md` 和 `AGENTS.md` 的读取；WorkBuddy 也支持 skill。README 提醒这些工具更新很快，以各自当前官方文档为准。
15. **把作者的工作流拆成可迁移的六阶段**（README 对 harness 的一句话描述，用于第 2、3、5 课）：**审查 → 清理 → 计划 → 执行 → 审阅 → 发布**。
16. **每课结束都对验收清单自查**，交付物以“别人能重跑”为准，不以“我跑出来了”为准。
