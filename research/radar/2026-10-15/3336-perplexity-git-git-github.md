## 是什么

Perplexity 团队为智能体自建了一套 Git 锻造（forge）平台，作者（AravSrinivas）用三句话描述了它的形态：

```
每个 Perplexity 项目都是一个 Git 仓库。我们为智能体构建了一个 Git 锻造平台，没有 GitHub 的臃肿，因为无需任何人批准任何内容。

每个智能体都有自己的短期沙盒，并提交到一个共享的 S3 仓库上。提交冲突的比例不到 2%。

智能体使用普通的 `ls` 和 `grep`
```

要点：仓库粒度是“项目”；每个智能体各自在短期（用完即弃）沙盒里工作，改动提交到一个共享的 S3 仓库；因为不需要人工审批，所以不需要 GitHub 那套 PR / 评审流程；智能体做代码检索时只用最普通的 `ls` / `grep`。原文属于对内部工具形态的概述，不是教程。
