**判断有没有改善的指标：**

- 从告警产生到「根因假设」产出的时间（对比人工）。
- Agent 给出的根因假设被人工判定为**正确**的比例；只算能验证的那些条目。

- 误报/无法复现的告警占比，以及被自动归并的重复告警比例。
- 反向指标：人工为了校验 Agent 结论而额外花的时间——如果这项抵消了前面所有收益，就说明还不该推广。
