## 怎么试、怎么验证（最小试用方式和判断有没有改善的指标）

最小试用：选一个中小型仓库，在一个迭代内只对涉及界面变更的 PR 启用代理截图，并要求代理在 PR 评论中列出变更影响面和合并风险点；先不自动阻断合并，只作为评审参考。

判断指标：

- 截图是否覆盖目标变更，是否减少评审者手动复现界面的时间；
- 风险拆解是否指出真实问题，误报和漏报各有多少；
- PR 从提交到合并的时间是否缩短；
- 合并后与变更相关的缺陷是否减少；
- 评审者是否认为该评论有助于决策。

如果无法稳定获得截图、风险拆解质量不可评估，或评审者普遍忽略该评论，则不应升级为正式流程。
